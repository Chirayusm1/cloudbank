# CloudBank

CloudBank is a full-stack banking application built as a practical learning and portfolio project.

## Technology Stack

* .NET 8
* ASP.NET Core Web API
* C#
* SQL Server
* Entity Framework Core
* React
* Redis
* Docker
* AWS
* AWS SQS
* GitHub Actions

## Planned Features

* User registration and authentication
* JWT-based authorization
* Bank account management
* Money transfers
* Transaction history
* Redis caching
* Asynchronous processing with queues
* React dashboard
* Dockerized development environment
* AWS deployment
* CI/CD with GitHub Actions

## Architecture

The application will follow a modular full-stack architecture consisting of:

* React frontend
* ASP.NET Core backend
* SQL Server database
* Redis cache
* Queue-based background processing
* AWS infrastructure
* GitHub Actions CI/CD
